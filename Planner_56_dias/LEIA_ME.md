# Planner de 56 dias

Abra Planner_56_dias.md para consultar o conteúdo completo. Cada pasta dia_XX contém dados próprios e enunciado editável, com espaço para resposta. Resolva no ambiente que preferir. Não precisa manter resultados do dia anterior.

O PDF contém uma página por dia, com campo de conclusão clicável; as respostas ficam em seu notebook ou no Markdown. Os dados do pacote são parte dos enunciados, não respostas. As previsões e logs fornecidos em alguns dias são entradas para auditoria.

CSVs: UTF-8, vírgula como separador; ponto decimal. Quando uma célula contém vírgula decimal deliberada, ela está entre aspas no CSV e documentada no exercício. Não preencher toda ausência com zero.

Instalação, se necessária: python -m pip install -r requirements.txt

Para pedir correção: informe Dia X e envie código/SQL, tabelas/gráficos e respostas de interpretação.

As bases Wine/Iris são pequenas amostras históricas para treino técnico, não recomendação de uso decisório real. IPCA é taxa percentual mensal e não nível de preços. Fontes e hashes estão no manifesto.
