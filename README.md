<a id="sobre-o-projeto"></a>
<p>

Um percurso de prática em Ciência de Dados, com exercícios independentes e dificuldade crescente. O foco é aprender a analisar, interpretar e justificar decisões — com atenção especial à estatística.

| [01–07](Planner_56_dias/dia_01/resolucao.ipynb) | Python e estatística descritiva |

<a id="como-explorar"></a>
<p>
  <img src="assets/readme/secao-03.png" alt="03 — Como explorar" width="100%">
</p>

1. Abra a pasta do dia.
2. Leia o enunciado no notebook `resolucao.ipynb`.
3. Consulte o código, os resultados e as interpretações disponíveis.

As resoluções serão adicionadas ao longo do estudo.
